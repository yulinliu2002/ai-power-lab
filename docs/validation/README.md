# Validation Records

Evidence that an implemented specification was verified: what was run,
against which spec and acceptance criteria, and the result.

This is the "Validation Record" step at the end of the PEOS workflow (see
`ENGINEERING.md`). Add one file per validated spec, e.g.
`SPEC-000-validation.md`, recording the verification commands used and
their output or summary.

Where relevant, note which of `ENGINEERING.md`'s four verification layers
(unit test, physics invariant, regression, scenario validation) each
piece of evidence corresponds to. AI review or agent claims of "done" are
not themselves validation evidence.
